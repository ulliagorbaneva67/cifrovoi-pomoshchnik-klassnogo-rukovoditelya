# Цифровой помощник классного руководителя

Локальный прототип для быстрой подготовки типовых документов классного руководителя. Внешние API и ИИ-сервисы не используются: связный текст формируется программными шаблонами, а Word-файл создаётся локально.

## Возможности

- Характеристика на обучающегося.
- Протокол родительского собрания.
- Анализ работы классного руководителя за учебный год.
- Предпросмотр результата и редактирование исходных данных.
- Реальное скачивание редактируемого файла `.docx`.

## Запуск

Требуется Python 3.10 или новее. В папке проекта выполните:

```text
python app.py
```

Откройте в браузере: http://127.0.0.1:8000

Созданные Word-файлы сохраняются в папке `generated/`.

## Технологии

Python standard library (`http.server`, `zipfile`, XML), HTML, CSS и JavaScript без сборщика и внешних зависимостей.

## Как добавить документ

1. Добавьте описание полей в объект `configs` в `static/app.js`.
2. Добавьте генератор текста для нового ключа в `paragraphs_for` в `app.py`.
3. Добавьте название и имя файла в словари `titles` и `safe_filename`.

Такой подход позволяет добавлять новые шаблоны без изменения общего пользовательского сценария.
